# Always show the interactive app after changes

After editing any mobile app file or making any user-visible app change:

1. Run the relevant type checks and tests.
2. Rebuild the web preview in `apps/mobile/.expo-live-preview`.
3. Ensure the preview is running at `http://127.0.0.1:8104/`.
4. Include that clickable interactive preview link in the same final response.

Do not hand off an app change with only a written description or static screenshot
when the interactive local preview can be rebuilt.
